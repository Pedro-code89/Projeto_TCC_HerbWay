# 🌿 HerbWay

> **Conectando pessoas à jardinagem de um jeito simples.**

O **HerbWay** é um projeto desenvolvido como TCC com o objetivo de facilitar o acesso a serviços de jardinagem, aproximando clientes de profissionais da área.

A plataforma permite encontrar jardineiros, visualizar informações sobre seus serviços e facilitar o contato entre profissional e cliente.

---

## 🎯 Objetivo

Criar uma plataforma simples e intuitiva para **conectar clientes e jardineiros**, tornando mais fácil encontrar profissionais para diferentes tipos de serviços de jardinagem.

## ✨ Funcionalidades

* 🔎 Busca por jardineiros
* 👨‍🌾 Perfis de profissionais
* 📋 Visualização de serviços
* 📍 Localização e informações dos profissionais
* 💬 Facilitação do contato entre cliente e jardineiro
* 🌱 Interface voltada para o universo da jardinagem

## 🛠️ Tecnologias

* HTML
* CSS
* JavaScript
* JS
* NODE.JS
* EJS

## 📌 Projeto

**HerbWay** foi desenvolvido como projeto de **Trabalho de Conclusão de Curso (TCC)**, unindo desenvolvimento web, organização de dados e uma proposta voltada para serviços de jardinagem.
